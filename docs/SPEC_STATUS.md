## 부분 충족과 이유
| ID | 이유 |
|---|---|
| T01-01 | 시간 조건만 자동 판정. 시간 조건이 아니면 사용자가 '차량에서 운전 자제 안내를 받았어요'를 직접 확인해야 할인권 사용 |
| M01-01 | 휴대전화번호·인증번호 확인 없음(이름만으로 가입, 계정 토큰은 기기에 저장) |
| M02-03 | 고속국도 자제만. 주요 운전 지역(생활권) 설정 없음 |
| M03-01 | QR 스캔 없음. 6자리 연결번호 입력만 |
| M03-04 | 연결 실패 안내·해제는 되지만 E01-02(잘못된 계정 재선택) 흐름은 따로 없음 |
| V03-02 | NaviHelper에 고속도로 회피 옵션이 없어 무료도로 우선 재탐색. 에뮬레이터 내비는 옵션 변경을 반영하지 않아 남으면 '유료도로 우회' 안내 |
| E02-03 | 마지막 동기화 값 표시·복구는 되지만 오프라인 중 수정분을 모아 보내는 기능 없음(저장 실패 팝업으로 재시도) |
